1 Download SQLiteExporter by XaviCya & SQL Editor - useful tool if you want to edit saves that are over 6MB
https://mega.nz/file/rRhhUKbJ#0XKD1g2PIc82zvBTcBJDDu4tF6eOqpqsMt_ZxY9Hrzo

2 Put SQLiteExporter.exe and pcmexporter.bat in the same directory (Example c:\pcm24exporterdir)

3 Open command line

4a if you want export the sqlite db from cdb file, you must use this command

	./pcmexporter.bat export <pcmusername> <carrerfilename>
	
4b if you want import the sqlite db into cdb file, you must use this command

	./pcmexporter.bat import <pcmusername> <carrerfilename>	
	
5 Use a dbviewer to explore or edit sqlite database
